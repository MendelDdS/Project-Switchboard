# Playtesting: self-check / 自检清单

- [ ] 测试者要对应 FTUE、核心、硬核三类人设 / Playtesters match the FTUE, Core, or Hardcore persona
- [ ] 观察者不提示不引导，卡住 5 分钟只记录 / Silent observer: no hints, just notes
- [ ] 反馈分成 UX 摩擦、难度校准、功能噪声三类 / Sort feedback into UX friction, difficulty tuning, or feature noise
- [ ] 访谈用开放式问题，不问“你喜欢吗”“是不是太难” / Ask open-ended, non-leading questions
- [ ] 不直接实现玩家提的功能，先找背后的真实问题 / Don't build player-suggested features; find the root friction
